# nimtools

A high-performance toolkit written in Nim leveraging Nim's built-in compiler AST front-end for static analysis, outline generation, cyclomatic complexity auditing, and deterministic refactoring for developers and AI agents.

## Included Tools

### 1. `nimoutline`
Parses a Nim source file and generates a concise summary text file containing:
- **One-line type definitions** (`object`, `enum`, `tuple`, `distinct`, `ref/ptr`, variant objects).
- **Clean routine signatures** (`proc`, `func`, `iterator`, `template`, `macro`, `method`, `converter`) without bodies or internal comments.
- Line numbers for fast reference.

```bash
nim c -d:release nimoutline.nim
./nimoutline <input_file.nim> [-o <output.txt>]
```

### 2. `cyc`
Measures **McCabe Cyclomatic Complexity** on the real compiler AST.
- Accurately discounts string literals and dispatch-only `of` arms.
- Identifies control flow decision points (`if`, `elif`, `while`, `for`, `and`, `or`, `except`, non-dispatch `case`).
- Supports thresholds: `--gate N` (max ceiling), `--budget N` (count over 5), `--debt N` (sum of complexity over 5), and `--heavy N` (monster procs $\ge 15$).

```bash
nim c -d:release cyc.nim
./cyc [--gate N] [--budget N] [--debt N] [--heavy N] FILE...
```
